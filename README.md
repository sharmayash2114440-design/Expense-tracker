# Expense Tracker

A simple Python-based Expense Tracker that allows users to add, view, and manage their expenses.

## Features

- Add expenses
- View all expenses
- Store expenses in a text file
- Validate user input
- Calculate expense amounts
- Organize expenses using Python dictionaries

## Technologies Used

- Python
- File Handling
- Lists
- Dictionaries
- Functions
- Exception Handling

## How to Run

1. Make sure Python is installed.
2. Open the project folder.
3. Run:

```bash
python main.py
